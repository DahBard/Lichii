## lichii-tuned

This fork's `tuned` branch builds a tuned Windows Lichii for the owner's laptop (Core Ultra 7 255H +
RX 9070 XT over OCuLink, testing Ocarina of Time). Since round 16 the same workflow run also builds
a CachyOS (Linux) package; the owner asked to update it alongside the Windows build every round
and for it to run on any modern Intel CPU (x86-64-v3, no AVX-512). The build workflow, what the
tuned build contains, the test results and the next steps are in @lichii-tuned/HANDOFF.md.
